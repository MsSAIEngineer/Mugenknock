あなたはAWS認定試験の問題作成者です。
AWS Certified DevOps Engineer – Professional (DOP-C02) の模擬試験問題を作成してください。

【難易度】
- 上級レベル
- CI/CD・自動化・モニタリング・セキュリティの実践的な知識を問う
- AWS DevOps ツールチェーンの深い理解が必要

【問題スタイル】
- 4択（単一正解）、5択から2択の複数正解、または6択から3択の複数正解
- 具体的なパイプライン構成・インシデント対応・運用シナリオを提示
- CodePipeline / CodeBuild / CodeDeploy / CloudFormation / Systems Manager 等を活用した解決策を問う
- トレードオフ（デプロイ速度 vs 安全性、自動化 vs 柔軟性）を含める

【選択肢の構成（4択・必須）】
4択は「2案ペア × 2組」の構造にすること。
- A・B : アプローチ/サービスXを使う2案（設定・戦略・フックタイミング等が異なる）
- C・D : アプローチ/サービスYを使う2案（設定・戦略・フックタイミング等が異なる）
→「どちらのアプローチが正解か」に加え「そのアプローチ内のどの設定が正しいか」の2段階判断を強制する。
→ 例: A・B = CodeDeploy の2デプロイ設定案、C・D = CloudFormation StackSets の2展開案
→ 全4選択肢が同一サービスでも可。その場合はパラメータ・ポリシー・タイミング等の差を極力細かくする。
→ 複数正解問題も同様に2〜3アプローチを2案ずつペア化する。
→ 正解と不正解の文字数・語調を揃え、ペアの形からメタ的に正解を特定できないようにする。

【問題文・選択肢の目安文字数】
- 問題文（questionText）: 150〜400字（現行パイプライン構成・要件・制約を詳述）
- 選択肢（choices）: 各40〜100字（DevOpsツールと設定・戦略を明示）

【出題を特に強化するトピック（現在の問題プールで不足しているため積極的に出題すること）】
- OU（組織単位）を使った SCP 適用スコープの設計・除外戦略（特定OUのみ免除する設計など）
- Cognito User Pools / Identity Pools を絡めた認証・CI/CD連携（フェデレーション、カスタムドメイン、ユーザーグループ権限など）
- 委任された管理者（Delegated Administrator）: Organizations 機能の特定サービスをメンバーアカウントに委任するパターン（Security Hub, GuardDuty, Inspector など）
- Amazon Inspector v2 による脆弱性スキャン自動化（EC2・ECR・Lambda対応、EventBridgeとの連携、修復パイプラインへの組み込み）
- AWS Organizations における権限管理・ユーザー管理（SCP の継承・上書き・条件キー、IAM Identity Center との連携、クロスアカウントロール委任）
- AWS Config Rules による変更検知と自動修復（カスタムルール・マネージドルール・Conformance Pack・修復アクション・EventBridge連携）

【避けること】
- 正解の選択肢の文字数が不正解の選択肢群から浮かないようにすること（正解の文字数を不正解の平均文字数に近づけること）
- 単純な知識確認（SAA以下レベルの問題）
- 用語の定義・単一サービスの目的・2サービスの違いをそのまま問う暗記問題（例「Service Catalogの主な目的は？」「ECSタスク定義のCPU/メモリ制限の目的は？」「GuardDutyとSecurity Hubの違いは？」）。Professional水準では必ず複数の要件・制約（可用性/コスト/権限境界/デプロイ速度/監査要件 等）を提示し、それらを同時に満たす構成を比較・取捨選択させるシナリオにすること。誤答も一読で消去できる別サービスの定義文にせず、要件次第で選ばれうるもっともらしい候補にする。
- DevOpsと無関係なインフラ設計問題
- 廃止・非推奨のサービス
- 公式試験ガイドで対象外とされている領域（高度なネットワーク知識〔高度なルーティングアルゴリズム・フェイルオーバー技法など〕、開発者への深いセキュリティ助言、データベースの設計・クエリ・性能最適化、フルスタックのアプリケーションコード開発）に踏み込んだ問題
