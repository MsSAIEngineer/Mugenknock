# 解いた問題の「もっと知りたい」質問

- 状態: 完了（2026-10-28）
- 起票日: 2026-10-28

## なぜやるか

解説を読んだあとに、関連する用語や「条件が違ったら」を自分で調べようとしても、何を聞けばよいかを考える手間がかかる。
問題ごとに、プラスアルファで知っておきたいことを質問の形で用意しておき、利用者が自分の AI（ChatGPT・Claude など）に
そのまま貼って聞けるようにする。

（2026-09-15 に廃止した「質問プロンプト生成」（`PromptMenu`、specs/002）は、どの問題にも同じ型のプロンプトを作るドロップダウンで、
ボタンが散らかる原因だった。今回は問題ごとに中身の違う質問を、解説の後に読み物として置く。）

## 誰のためか

- [x] ゲスト（未ログイン）
- [x] ログインユーザー
- [x] 管理者
- [x] 開発者・運用（自分）

ゲストにも出す。問題に付いた固定の文を表示してコピーするだけで、ローカルに何も溜めないため（CLAUDE.md の境界に反しない）。

## 何を作るか

1. 演習画面（`ExerciseSession`）で回答したあと、コラムの上に「もっと知りたいとき」として質問を最大3つ出す。
   各質問の横にコピーのボタンを置き、押すと**質問文だけ**をクリップボードへ写す。
2. 問題データを走査して質問を付けるスクリプト。**1周で1問につき1つ**付け、最大3つまで。
   質問の少ない問題から順に付ける（全問が1つになってから2つ目に進む）。軽いモデル（Haiku）を使う。
3. 質問の角度は次の5つ。1問に付く質問は、すべて別の角度にする。問題に合わない角度は使わない。

| 角度 | 例 |
|---|---|
| 用語（`term`） | 正解以外の選択肢の用語について「xxxとは？」 |
| 違い（`diff`） | 正解と他の選択肢の用語の「xxxとyyyの違いは？」「使い分けは？」 |
| もし条件が違ったら（`whatif`） | 「コストを最優先にするなら、xxxではなく何を選ぶ？」 |
| 仕組み・なぜ（`why`） | 「xxxはなぜリージョン障害に強いの？」 |
| 制限・料金・注意点（`limits`） | 「xxxの上限（クォータ）や料金の仕組みは？」 |

4. 使い切りモード（`ct on`）のとき、生成(01)・検証(02)と同じくピン前の余った枠で自動で動く。手動でも動かせる（エイリアス `afq`）。

## 受入条件

- [x] 回答後、質問のある問題ではコラムの上に質問が出て、コピーで質問文だけが写る。回答前には出ない
- [x] 質問のない問題では何も出ない（空の見出しも出ない）
- [x] 質問は「この問題」「選択肢A」などを使わず、それだけで意味が通る
- [x] オリジナル資格（ML/DB/NW/SEC）の質問に AWS のサービス名が出ない
- [x] 1問の質問は3つまでで、角度が重ならない
- [x] 問題の選択肢があとから直されたら、古い質問は画面に出さず、スクリプトが付け直す
- [x] `afq -n 10` のように手動で動かせ、`-D HH:MM` で止まる

## 対象外（やらないこと）

- 模擬試験（`ExamSession`）・図鑑など、演習画面以外への表示
- 質問への回答の表示（回答は利用者の AI に任せる）
- 管理画面での質問の編集（必要になったら別 spec）
- 英語版
