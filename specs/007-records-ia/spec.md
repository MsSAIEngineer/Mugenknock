# 成績・履歴の置き場所の整理（ホーム／マイページ／統計）

- 状態: 下書き
- 起票日: 2026-10-26

## なぜやるか

同じ種類の情報が3画面に散らばっていて、どこを見ればよいか分からない。しかも画面ごとに集計の窓が違うため、
同じ「ドメイン別の正答率」でも画面によって数字が変わる。
（2026-10-26 のデザイン監査の指摘19。Nielsen の「一貫性と標準」「記憶より認識」に反する。）

現状の重複（コードで確認済み）:

| 情報 | ホーム `/aws/` | マイページ `/aws/mypage` | 統計 `/aws/stats` |
|---|---|---|---|
| ドメイン別の成績 | 実力の現在地（直近5/10問のノード） | 苦手分析タブ（直近10/20/30問） | ノック成績タブ（累計） |
| スコアの推移 | 推移と記録（セッション別・日次最高点・ハイスコア） | — | ノック成績タブのセッション別スコアチャート |
| セッション履歴 | — | 履歴タブ（直近10件・展開で問題別の正誤） | ノック履歴タブ（最大200件・展開・ブックマーク操作） |
| 活動量 | 目標演習量（今日） | 週間達成状況（7日） | 日次ノック量（7/14/30日/全期間） |
| 苦手分析 | 右カラムの要約カード（PCのみ） | 苦手分析タブ（本体） | — |

さらに、**統計画面にはナビ（サイドバー・下部タブ・その他）からの入口がない。**
到達経路は模試設定画面（`/aws/exam/setup`）の「ノック成績 →」リンク1か所だけで、
200件の履歴や全期間の活動量といった統計画面にしかない情報が、実質的に見つけられない。

画面名も分かりにくい。「ノック量・ノック成績・ノック履歴」はサービス名からの造語で、初めての人には中身が想像できない。

## 何を作るか

各画面の役割を1つに決め、情報をその役割の画面に寄せる。具体的な寄せ方は「未決事項」の案から選ぶ。

どの案でも共通にすること:
- 1つの情報（例: セッション履歴）の本体は1画面だけに置く。他の画面には要約と、本体へのリンクだけを置く。
- 「ドメイン別の成績」は、画面ごとに違う窓で集計しない。窓を変えたいときは同じ画面の切り替えで行い、窓を必ず表示する。
- 統計の情報にナビから辿れるようにする（孤立したページを残さない）。
- 画面・タブ名は中身が分かる言葉にする（例: 「ノック履歴」→「解答履歴」）。

## 受入条件

- [ ] 上の表の5種類の情報それぞれについて、本体を置く画面が1つに決まっている（docs/05-screens.md に明記）
- [ ] 本体以外の画面に同じ一覧・グラフが重複していない（要約カード＋リンクは可）
- [ ] 成績・履歴の画面に、サイドバー（PC）と下部タブ／その他（スマホ）のどちらからでも2タップ以内で着く
- [ ] ドメイン別の成績を表示する箇所すべてに、集計の窓（「直近10問」「累計」など）が表示されている
- [ ] 既存の外部遷移（ホーム苦手分析カード → `/aws/mypage` の analysis タブ、模試設定 → 統計）が、整理後の置き場所へ正しく飛ぶ
- [ ] 既存の URL（`/aws/stats` `/aws/mypage`）をブックマークしている人が 404 にならない

## 対象外（やらないこと）

- 苦手分析の中身（粒度をドメインより細かくする等。docs/09 の 2.1）は変えない。置き場所だけを扱う
- API・DynamoDB の変更はしない（今ある取得 API の組み合わせで足りる前提。足りないと分かったら plan で再検討）
- ゲスト向けの成績表示は作らない
- ホームの「実力の現在地」の計算方法（予想スコア）は変えない

## 影響範囲

| 種別 | 影響 |
|---|---|
| 画面 | Home・MyPage・Stats・Layout（ナビ）・ExamSetup（リンク先） |
| API | なし（の想定） |
| DynamoDB | なし |
| 夜間バッチ | なし（ただし e2e/canary が画面構成に依存していないか plan で確認） |
| デプロイ | フロントのみ |

## 既存の不変条件との整合

- 出題プールの条件 `!isHidden && !!validityCheckedAt` を維持するか: はい（触らない）
- ドメイン均等化（deficit round-robin）の方針に反しないか: 反しない（出題に触れない）
- ゲスト/ログイン境界に反しないか: 反しない（ログイン専用のまま）
- `correctAnswerIndices` を正準とする不変条件に触れるか: 触れない

## 未決事項

- **どの案で寄せるか**（本人が決める）
  - 案A「統計に集約」: ホーム＝今の実力と今日やること、マイページ＝設定（目標・受験日・取得資格・ブックマーク）、
    統計＝過去の記録すべて（推移・解答履歴・活動量・ドメイン別・苦手分析）。統計をナビに出す。
    マイページの苦手分析・履歴タブは統計へ移す
  - 案B「マイページに集約」: 統計画面を廃止し、その中身をマイページのタブに入れる（目標／苦手分析／記録）。
    `/aws/stats` はマイページの記録タブへ転送する。ナビの項目は増えない
  - 案C「最小限」: 構成は変えず、統計をナビに出す・名前を直す・窓を表示するだけ。重複は残る
- ホームの「推移と記録」（PC 左カラム）を残すか、要約＋リンクにするか（案A/Bのどちらでも論点になる）
