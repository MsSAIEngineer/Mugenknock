## 実装後のメモ

- タスク1〜3（切り出し・記録の組み替え・マイページの整理）は、マイページから消すコードと記録に足すコードが
  対になっていて途中の状態に意味がないため、1コミットにまとめた。
- 記録画面は目標資格を localStorage から読んでおり、新しいブラウザで直接 URL を開くとタブが出なかった。
  トレーニング画面と同じく `targetExamChanged` を購読するようにした。e2e もホームを先に開く（演習テストと同じ）。
- `npm run lint:tokens` は、移設したコードの生の値を新しいファイルの違反として数える。基準を上げずに、
  移設先（WeakAnalysis.tsx）の値をトークンへ直した（全体 1,718 → 1,657 件）。角丸 0 は違反から外した。
- ローカルで canary を流すとログイン状態が引き継がれなかった（storageState の環境要因）。検証は検証環境の canary で行う。
- マイページの `ExamCardHeader` 等を描画中に定義している既存の書き方が、タブ条件の外に出たことで
  react-hooks の lint エラーとして出るようになった（ビルドは ESLint 無視なので影響なし）。今回は直していない。
